# EloGuard Chrome Web Store Description - V2

## Short Description

Local Stockfish game reviews and stop-loss rating locks for calmer, less tilted Chess.com sessions.

## Full Description

EloGuard helps you play cleaner Chess.com sessions.

It gives you local post-game reviews and hard rating limits that stop you from rage-queueing after a bad loss or pushing too far after hitting your goal.

Built for Bullet, Blitz, and Rapid on the desktop/web version of Chess.com.

1. Local Game Review

After a game, EloGuard adds a Game Review button directly on Chess.com.

Review runs Stockfish 18 locally in your browser, so your game analysis is done on your machine. EloGuard does not upload your games for review.

- Accuracy and ACPL.
- Move labels such as Brilliant, Great, Best, Mistake, Miss, and Blunder.
- Opening name when recognized.
- Accuracy by opening, middlegame, and endgame.
- Move-by-move navigation with board highlights.
- A "played like" estimate when ratings are available.
- Adjustable depth if you want faster or stronger analysis.

EloGuard also adds an Analyze on Lichess button for players who prefer that workflow.

Free users get limited daily Game Reviews. EloGuard Pro unlocks unlimited reviews.

2. Stop-Loss And Target Locks

EloGuard helps you stop at the rating boundaries you set before emotions take over.

Set a stop-loss floor. If your Chess.com rating drops to that number, EloGuard locks the Play, New Game, and Rematch buttons.

Set a target ceiling. If you reach your goal, EloGuard locks the buttons with a goal-hit message so you can end the session while ahead.

You can also lock after a chosen number of consecutive rating drops.

3. Analysis Cooldown

If you tend to skip review and instantly queue again, set a cooldown after each completed game.

For example, a 60-second cooldown gives you a short pause to breathe, check the critical moment, and avoid playing the next game purely on tilt.

Cooldown does not trigger on aborted games.

4. Zen And Focus Tools

EloGuard can make Chess.com feel less noisy:

- Zen Mode hides rating numbers.
- Anonymize Opponent hides opponent names, ratings, titles, countries, flair, and avatars.
- Hide My Profile hides your own visible player/rating details.
- Enhanced Focus Mode creates a cleaner board-focused layout with clocks, captured material, a flip control, and a focus toggle fixed in the top-right.

5. Strength Profile

EloGuard Pro turns your reviewed games into a bigger performance picture.

My Stats / Strength Profile shows how you are playing across time controls, recent games, and game phases. You can also analyze recent Chess.com games in batches, such as last 10, last 25, last 50, last week, last month, or last 3 months.

6. Smart Bracket

Smart Bracket sets your stop-loss floor and target ceiling automatically.

Enter a range like +/- 25, and EloGuard builds the session bracket around your current live rating.

Smart Bracket is included with EloGuard Pro.

FAQ

Does EloGuard work on the Chess.com mobile app?

No. EloGuard is a Chrome extension for the desktop/web version of Chess.com.

Why do I need to enter my Chess.com username?

EloGuard uses your username to fetch public Chess.com stats, read your current rating, apply the right Bullet/Blitz/Rapid limits, and build your review profile.

Can I unlock the Play button?

Yes. You can turn the guard off from the extension popup. If Random String Unlock is enabled, you must type the generated string first, which adds a small moment of friction before you bypass your own limits.

Does Game Review upload my games?

No. Stockfish review runs locally in your browser. Review history is stored locally by the extension.

What data is sent for Pro?

EloGuard uses a random extension install ID to check Pro status with the EloGuard billing server. Payments are handled by Stripe. EloGuard does not store card details.
